# إدارة الطالب

تطبيق إدارة دراسية محلي يعمل كواجهة أمامية ثابتة، بدون React أو Express أو Node.js أو أي framework. الملفات الأساسية هي `index.html` و`style.css` و`script.js`، والصور داخل مجلد `Image`.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو ارفع المجلد كاملًا إلى مستودع GitHub وفعّل GitHub Pages من إعدادات المستودع. لا توجد قاعدة بيانات أو حسابات؛ البيانات تُحفظ في `localStorage` داخل المتصفح.

## الخصائص

يدعم التطبيق ملفات طلاب متعددة مع تطبيع الاسم ومنع التكرار، وعزل البيانات بين الملفات، وتعديل وحذف المواد والمهام والجلسات والاختبارات، وحساب نسبة الاختبار تلقائيًا من الدرجة والدرجة الكاملة، ورفع صورة الاختبار وحفظها محليًا، وتسجيل الأوقات المشغولة، وتوليد خطة مذاكرة تلقائية قابلة للتعديل، وتبديل الوضع الفاتح والداكن مع حفظ الإعداد، واستيراد وتصدير JSON وإعادة ضبط البيانات.

الأيقونات تأتي من Font Awesome عبر CDN، بينما الصور المستخدمة موجودة محليًا في مجلد `Image`. لا توجد علامات مائية أو شعارات خارجية داخل الواجهة.
